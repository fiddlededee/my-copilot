## {#changes} Changes v1.1.0 → v1.2.0

### Key changes
- **Shared models extracted to a Maven Central library.** `Modification`, `ModificationList`, `ModificationType`, `generateSchema<T>()`, and `correctJson<T>()` were moved out of the copilot script into `ru.fiddlededee.mycopilot:my-copilot-models:1.2.0`. The script now depends on this library instead of defining these types and utilities inline. This eliminates the need for the kotlinx-serialization compiler plugin when running the copilot script.

### Other changes
- **`predefinedCommand()` extended** with a third command that queries Maven Central for the latest published version of `my-copilot-models`, making it easy to verify the library is available.
- **`Monitoring.saveToFile`** now uses `file.toURI()` instead of `"file://${file.absolutePath}"` for session log links (cleaner URI format).
- **Removed Doc hints about the kotlinx serialization compiler plugin** (lines about `kotlin -Xplugin` and "structured output won't work without kotlinx serialization compiler plugin") — no longer relevant.
- **Removed now-unused imports** related to inline schema generation: `InternalAgentToolsApi`, `defaultJsonSchemaConfig`, `getJsonSchema`, `typeToken`, `JsonSchemaConfig`, `JsonSchema`, `Serializable`.
- **`LlmCommon.correctJson` simplified** from a full multi-step implementation to a one-liner delegating to `ru.fiddlededee.mycopilot.models.correctJson(...)`.
- **`LlmCommon.generateSchema` removed** entirely — now imported from the library.
